# P3D-calculator - удобный калькулятор для расчета стоимости Вашей 3D печати от мастерской по 3d печати Pogodin_3D
Доступ к калькулятору осуществляется по ссылке - https://calc-p3d.vercel.app/

Удобный калькулятор в минималистичном дизайне, который упростит расчет стоимости печати.
В качестве значений по умолчанию взял цифры рандомные, поэтому на них не стоит ориентироваться, укажите свои цифры и пользуйтесь.

  Плюсы калькулятора:
1. Работает оффлайн (все данные хранит в кэше браузера)
2. Можно установить как полноценное приложение на телефон
3. Автоматическое сохранение всех введенных данных (без всяких кнопок сохранить и т.д.)
4. Темная тема, которая не режет глаз
5. Учитывает амортизацию оборудования, электроэнергию, считает себестоимость и многое другое
6. Простой и удобный в использовании

  ФИШКИ:
1. Возможность добавить на итоговый расчетный лист свою печать (снизу кнопка "добавить печать")
2. Сохранение для клиента расчетного листа в виде картинки (снизу кнопка "сохранить")

Добро пожаловать в мой мир 3D печати! Приятного использования!
